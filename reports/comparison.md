# 세 전략의 과거 모의투자 비교
작성: 2026-09-22. Binance BTCUSDT USDⓈ-M 무기한 선물. **Jev 미사용 결과**입니다. 실제 과거 데이터를 내려받아 실행했으며 임의 수익률을 만들지 않았습니다.
## 결론

세 전략 모두 손실이며 실거래 채택 기준을 충족하지 못했습니다. 거래하지 않은 현금 기준 수익률 0%에도 못 미칩니다. 추세 눌림목의 평가 구간 손실이 상대적으로 작지만 수익 전략으로 추천할 근거는 없습니다.
## 비교 설계

각 실행은 10,000 USDT에서 독립적으로 시작합니다. 2025-08은 지표 준비용, 2025-09-01~2026-05-31은 참고 구간, 2026-06-01~2026-08-31은 별도 평가 구간입니다. 전체 구간도 독립 실행했습니다. 모두 UTC 기준입니다. 조건은 결과를 보기 전에 정했고, 평가 결과를 보고 파라미터를 조정하지 않았습니다. 다만 과거 구간 하나의 일회성 비교이므로 전진 검증이나 수익성 입증으로 부르지 않습니다.
거래당 목표 손실 예산 0.5%(추정 왕복 비용 포함), 최대 명목금액/잔고 2배, 동시 포지션 1개, 추가 매수 없음. 당일 시작 잔고 대비 2% 손실이면 그날 진입 중지 및 남은 포지션 종료, 종가 기준 고점 대비 10% 하락이면 해당 실행의 남은 기간 전체 거래 중지입니다. 임계값에서 즉시 정확히 체결된다는 보장은 없으며 모의 결과도 이를 초과할 수 있습니다.
편도 수수료 0.05%, 편도 불리한 체결 오차 0.02%를 가정했습니다. 이는 실제 계정 수수료를 조회한 값이 아닙니다. 비용 스트레스에서는 체결 오차만 편도 0.05%로 높였습니다. 실제 기록된 펀딩비율을 사용하되, 펀딩 명목금액에는 해당 봉 시가를 표시가격 대용으로 사용했습니다. AI 호출비·서버비·세금은 포함하지 않았습니다.

## 해석할 때 주의할 점

- **모든 실행에서 10% 낙폭 제한이 작동했습니다.** 중지 뒤에는 잔고를 유지합니다. 따라서 12개월 내내 거래한 결과가 아니며, 중지 이후 시장 성과를 측정하지 않았습니다. 전체 구간과 참고 구간의 결과가 같은 것은 이 때문입니다.
- 최대 낙폭은 시작 자금 대비 손실이 아니라, 실행 중 잔고 고점 대비 하락률입니다. 추세 전략의 최종 손실이 약 4%이면서 낙폭이 10% 이상일 수 있습니다.
- 최대 낙폭과 일일 손실은 봉 시가/종가 및 체결 시점으로 관측합니다. 봉 내부의 순간 낙폭은 완전히 포착하지 못합니다.
- PF는 이익 거래 손익 합계/손실 거래 손익 절댓값 합계입니다. 비용과 펀딩을 포함하며 1보다 작으면 총손실이 더 큽니다.
- 숫자 신호는 완료된 봉으로만 계산하고 다음 봉 시가에 진입합니다. 한 봉에서 손절과 익절이 모두 닿으면 손절을 먼저 처리합니다. 가격이 손절가를 뛰어넘으면 봉 시가에 체결 오차를 추가합니다.
- 펀딩 이벤트는 15분봉으로 정렬하고 기존 포지션에 먼저 반영한 뒤 신규 진입을 처리합니다. 수 밀리초 수준의 실제 정산 순서를 재현하지 않습니다.
- 최소 주문 명목금액 100 USDT, 수량 단위 0.001 BTC는 연구 가정입니다. 과거 거래소 필터·부분체결·주문 대기열·시장충격·표시가격 기준 강제청산을 재현하지 않았습니다. 특히 실제 손절의 체결을 보장하지 않습니다.
- 이 비교는 바이낸스 데모 계정 거래나 앞으로의 실시간 모의투자가 아닙니다.
## Jev 검증 상태

공식 HTTP API 규격에 맞춘 연결 코드와 조건 전달·응답 검증은 구현했습니다. API 키가 없어 **실제 Jev 요청 및 Jev 수익률 비교는 실행하지 않았습니다**. 테스트용 응답은 기능 검증에만 사용했습니다. Jev를 붙인 과거 재생은 모델의 과거 학습 정보와 실제 API 지연 때문에 추가 편향이 생길 수 있습니다. 앞으로의 시점에서 판단을 기록하는 전진 모의투자가 후속 단계입니다.
